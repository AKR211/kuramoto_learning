# Contrastive Learning in the Kuramoto Model

This repository contains a Python implementation of the PAR learning process for the kuramoto model as described in the below paper

**Contrastive learning in tunable dynamical systems**  
*Stern, M., Frim, A. G., Candás, R., Liu, A. J., & Balasubramanian, V. (2026)*  
DOI: [10.48550/arXiv.2603.26969](https://doi.org/10.48550/arXiv.2603.26969)
